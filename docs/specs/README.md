# Specs

One file per area. A spec says **what** a feature does: inputs, outputs, units, meaning, edge cases,
refusals, in our own words. It never describes or names another program (AGENTS.md "Independence").
Specs marked *Outline* are placeholders to be filled in by the PR that claims the feature.

Lessons learned about real files are written as behaviour ("real STL exports often repeat vertices
with -0 and 0"), never as another program's code structure.
